# Roadmap

## AdSense readiness
- [x] Sourcing decision: owner pastes articles manually in the admin (or uses the built-in AI generator). Third-party RSS/XML article copying is out — copied content is against AdSense policy.
- [x] Admin "Write / paste" tab: title, markdown body, category, tags, summary, image URL, SEO title/description, slug, draft or publish
- [x] Ad settings: publisher ID, four slot IDs, on/off switch, "hide ads from signed-in users", contact email
- [x] Ad placements on blog listing (footer + sidebar) and article pages (in-article + sidebar), labelled, only for visitors
- [x] Public pages AdSense expects: /privacy, /about, /contact (contact form saves to an admin Messages inbox)
- [x] Verified: visitor sees ad slots, signed-in user sees none, switch off removes them; paste creates an article; pages return 200

## Waiting on the owner

- [ ] Publish more articles — aim for 15-25 before the AdSense application review
